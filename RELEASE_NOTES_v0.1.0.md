## LiteWall v0.1.0 (first release)

- Plays video (MP4/WebM/MKV/MOV, H.264/HEVC/VP9/AV1), animated GIF, and image wallpapers behind desktop icons at native resolution (up to 4K)
- Multi-monitor support, with one surface per display
- Hardware decoding through libmpv (D3D11VA) and below-normal process priority
- Auto-pause on fullscreen/maximized windows (per monitor), exclusive-fullscreen games, lock screen, and battery (can be turned off)
- EcoQoS and working-set trim while paused
- Tray menu: choose wallpaper, pause, fill/fit, auto-pause toggles, Start with Windows, quit
- Settings saved in `%APPDATA%\LiteWall\settings.ini`

### Download
| File | Platform |
|---|---|
| LiteWall-v0.1.0-win-x64.zip | Windows 10/11 x64 |

### Install
1. Extract the zip to any folder.
2. Run `LiteWall.exe` and pick a video, GIF, or image.
3. Right-click the tray icon for options.
