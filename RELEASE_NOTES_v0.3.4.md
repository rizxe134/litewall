## LiteWall v0.3.4

### Changes
- Fixed: after closing the library window with the X, opening LiteWall again showed nothing. LiteWall keeps running in the tray when you close the window, so launching it again now brings the library window back instead of stopping.

### Download
| File | Platform |
|---|---|
| LiteWall-v0.3.4-win-x64.zip | Windows 10/11 x64 |

### Install
1. Quit LiteWall (tray icon → Quit).
2. Extract the zip over your existing LiteWall folder. Your library and settings are kept.
3. Run `LiteWall.exe`.
